## The entry

> He died doing what he loved: ignoring the check-engine light.

The heroic epitaph formula ("died doing what he loved") promises a noble death; the payoff swaps nobility for a small, stubborn, instantly recognisable habit. The joke lands on the last words, needs no explanation, and fits on a stone.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) writes the epitaph deterministically to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and echoes it. It validates the gate first: UTF-8 text, 1–150 characters, a single non-empty line, plain ASCII.
